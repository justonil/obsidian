приложение для синхронизации плейлистов с локальной библиотекой. 
- версия на пк с основной логикой закачки(позже на мобильной тоже )
- версия для телефона
	- сканирует локальную библиотеку
		- записывает в файл для дальнейшей синхронизации с пк 
- треки помечаются тегами
- функция проверки правильности скаченных треков
